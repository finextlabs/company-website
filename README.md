# FinextLabs Website

Website for FinextLabs - building reliable software solutions for growing businesses.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Geist Font

## Project Structure

```
app/
├── layout.tsx       # Root layout with header and footer
├── page.tsx         # Homepage
└── globals.css      # Global styles
```
